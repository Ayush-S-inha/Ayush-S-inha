## What I'm Building

### [TraceFact](https://github.com/Ayush-S-inha/TraceFact)

A local tool built in Rust that observes application activity and compares it with a saved baseline. The goal is to make changes in software behavior easier to investigate, with findings connected to evidence.

**Working with:** Rust, SQLite, system observability, software testing.

### [Decide](https://github.com/Ayush-S-inha/Decide-Extension)

A Chrome extension that compares information from selected browser tabs to help turn scattered research into clearer decisions. It explores practical uses of language models while keeping the supporting evidence visible.

**Working with:** JavaScript, browser tools, applied AI.

### [TypeFlux](https://github.com/Ayush-S-inha/TypeFlux)

An ongoing experiment with webcam based hand tracking, gesture recognition, and real time visual effects. I'm improving the tracking and interactions through small, tested iterations.

**Working with:** JavaScript, computer vision, gesture interaction.
